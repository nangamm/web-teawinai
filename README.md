# Teawinai (เที่ยวไหน)

A full-stack web app that plans one-day trips in Ubon Ratchathani based on your budget. Set a total budget, and Teawinai recommends the best combination of attractions, restaurants, and cafés using a custom **Greedy Algorithm** to maximize value under budget constraints.

## Tech Stack
React · Node.js · MongoDB

## Features
- Set a budget and get an optimized one-day trip plan
- Cost breakdown to avoid overspending
- Browse recommended places in Ubon Ratchathani
