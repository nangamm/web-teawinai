# Admin Page คู่มือการใช้งาน

## สถานะปัจจุบัน ✅
- Backend: กำลังทำงานที่ http://localhost:5001
- Frontend: กำลังทำงานที่ http://localhost:3000
- Database: มีข้อมูลทดสอบแล้ว ✅
- Admin User: admin@teawinai.com / Admin1234 ✅

## ฟีเจอร์ที่ทำงานได้
- ✅ จัดการสถานที่ (เพิ่ม, แก้ไข, ลบ)
- ✅ จัดการการอัพเดทราคา (อนุมัติ, ปฏิเสธ)
- ✅ แสดงข้อมูลแบบ Real-time
- ✅ ภาษาไทยทั้งหมด
- ✅ Toast notifications
- ✅ Modal forms สำหรับ CRUD
- ✅ ความปลอดภัยด้วย role-based access

## ขั้นตอนการเข้าใช้งาน

### 1. เข้าสู่ระบบแบบ Admin
เข้าที่: http://localhost:3000/login
- อีเมล: `admin@teawinai.com`
- รหัสผ่าน: `Admin1234`

### 2. เข้าหน้า Admin Management
หลังจากเข้าสู่ระบบแล้ว:
- ไปที่ http://localhost:3000/admin/manage

### 3. ฟีเจอร์ที่สามารถใช้งานได้

#### 🗺️ จัดการสถานที่
- **ดูรายการสถานที่**: แสดงสถานที่ทั้งหมดในระบบ
- **เพิ่มสถานที่**: คลิก "เพิ่มสถานที่" เพื่อเพิ่มสถานที่ใหม่
- **แก้ไขสถานที่**: คลิกไอคอนแก้ไข (✏️) เพื่อแก้ไขข้อมูล
- **ลบสถานที่**: คลิกไอคอนลบ (🗑️) เพื่อลบสถานที่

#### 💰 จัดการการอัพเดทราคา
- **ดูรายการที่รออนุมัติ**: แสดงการอัพเดทราคาที่รอการอนุมัติ
- **อนุมัติ**: คลิก "อนุมัติ" เพื่ออนุมัติการอัพเดทราคา
- **ปฏิเสธ**: คลิก "ปฏิเสธ" และระบุเหตุผล

## ข้อมูลทดสอบในระบบ
- **สถานที่**: 15 แห่ง (วัด, คาเฟ่, ร้านอาหาร, สวนสาธารณะ)
- **หมวดหมู่**: 4 หมวดหมู่ (วัด, คาเฟ่, ร้านอาหาร, สวนสาธารณะ)
- **ผู้ใช้**: 3 คน (Admin, Owner, User)

## ฟอร์มเพิ่ม/แก้ไขสถานที่
- **ชื่อสถานที่**: ชื่อของสถานที่
- **หมวดหมู่**: เลือกจาก dropdown (วัด, หาด, ภูเขา, เมือง, พิพิธภัณฑ์, สวนสาธารณะ, ตลาด, ร้านอาหาร, อื่นๆ)
- **ที่อยู่**: ที่อยู่ของสถานที่
- **พิกัด**: ละติจูดและลองจิจูด
- **ราคา**: ราคาต่ำสุด-สูงสุด
- **เวลาเปิด-ปิด**: เวลาทำการ
- **URL รูปภาพ**: ลิงก์รูปภาพ (ไม่จำเป็น)

## หมายเหตุ
- หน้า Admin สามารถเข้าได้เฉพาะผู้ใช้ที่มี role = 'admin' เท่านั้น
- ข้อมูลจะแสดงเป็นภาษาไทยทั้งหมด
- มี notifications ภาษาไทยสำหรับทุกการกระทำ
- ระบบจะรีเฟรชข้อมูลอัตโนมัติหลังการกระทำ CRUD
