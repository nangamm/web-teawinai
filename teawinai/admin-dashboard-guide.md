# AdminDashboard คู่มือการใช้งาน

## สถานะปัจจุบัน ✅
- Backend: กำลังทำงานที่ http://localhost:5001
- Frontend: กำลังทำงานที่ http://localhost:3000
- Database: มีข้อมูลทดสอบแล้ว ✅
- Admin User: admin@teawinai.com / Admin1234 ✅

## ฟีเจอร์ที่ทำงานได้
- ✅ แสดงสถิติระบบ (จำนวนผู้ใช้, สถานที่, การอัพเดทราคาที่รออนุมัติ)
- ✅ แสดงรายการการอัพเดทราคาที่รออนุมัติ
- ✅ อนุมัติ/ปฏิเสธการอัพเดทราคา
- ✅ แจ้งเตือนภาษาไทย
- ✅ รีเฟรชข้อมูลอัตโนมัติ

## ขั้นตอนการทดสอบ

### 1. เข้าสู่ระบบแบบ Admin
เข้าที่: http://localhost:3000/login
- อีเมล: `admin@teawinai.com`
- รหัสผ่าน: `Admin1234`

### 2. เข้าหน้า Admin Dashboard
หลังจากเข้าสู่ระบบแล้ว:
- ไปที่ http://localhost:3000/admin
- หรือคลิกเมนู Admin (ถ้ามีใน Navbar)

### 3. ทดสอบฟีเจอร์ต่างๆ
- **ดูสถิติ**: ตรวจสอบจำนวนผู้ใช้, สถานที่, การอัพเดทที่รออนุมัติ
- **จัดการราคา**: อนุมัติหรือปฏิเสธการอัพเดทราคา
- **แจ้งเตือน**: ตรวจสอบข้อความแจ้งเตือนภาษาไทย

## ข้อมูลทดสอบในระบบ
- **ผู้ใช้**: 3 คน (Admin, Owner, User)
- **สถานที่**: 15 แห่ง (วัด, คาเฟ่, ร้านอาหาร, สวนสาธารณะ)
- **หมวดหมู่**: 4 หมวดหมู่

## หมายเหตุ
- หน้า AdminDashboard สามารถเข้าได้เฉพาะผู้ใช้ที่มี role = 'admin' เท่านั้น
- หากต้องการทดสอบการอัพเดทราคา ต้องมีข้อมูลใน PriceUpdate collection ก่อน
- ข้อมูลจะแสดงเป็นภาษาไทยทั้งหมด
